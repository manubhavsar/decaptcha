# deCAPTCHA

**A CAPTCHA that lets real agents through, not just real humans.**

A bot-detection gate that blocks anonymous bots exactly like every CAPTCHA does,
but lets an AI agent straight through if it carries proof that a real, verified
human vouched for it: scoped, expiring, and revocable the moment that human
pulls it back.

Built for ETHGlobal ETHOnline 2026.
Primary track: **World — Selfie Check**. Secondary: **ENS — Best Use of ENSv2**.
